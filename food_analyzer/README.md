# 🔍 FoodScan AI — Анализатор на хранителни продукти

> Мобилно Streamlit приложение за бърз анализ на хранителни продукти чрез OCR и баркод сканиране.

---

## 🚀 Бързо стартиране

```bash
# 1. Клонирай/разархивирай проекта
cd food_analyzer

# 2. Инсталирай Python зависимостите
pip install -r requirements.txt

# 3. (Опционално) Инсталирай системни библиотеки за пълна функционалност
# Ubuntu/Debian:
sudo apt-get install libzbar0 tesseract-ocr tesseract-ocr-bul

# macOS:
brew install zbar tesseract

# 4. Стартирай приложението
streamlit run app.py
```

Приложението се отваря на: `http://localhost:8501`

## ✨ Функционалности

### 📷 Сканиране
| Метод | Описание |
|-------|----------|
| **Демо продукти** | 7 предварително заредени продукта за тестване |
| **Качи снимка** | Качи JPG/PNG снимка на етикет → OCR + баркод |
| **Камера** | Снимай директно с камерата (мобилни устройства) |
| **Ръчен баркод** | Въведи EAN-13/UPC-A баркод ръчно |

### 📊 Анализ
- **Здравна оценка** 1-10 (алгоритъм базиран на калории, захар, мазнини, сол, добавки)
- **Хранителни стойности** с прогрес барове и % от дневна доза
- **Вредни добавки** — автоматично разпознаване на E-числа
- **Здравни рискове** — затлъстяване, диабет, сърце, кръвно налягане
- **Алтернативи** — по-здравословни заместители

### 🧪 База данни с E-та (25+ добавки)
| Категория | Примери |
|-----------|---------|
| Оцветители | E102, E110, E122, E123, E124, E129, E131 |
| Консерванти | E211, E220, E249, E250 |
| Усилватели на вкус | E621, E622 |
| Подсладители | E950, E951, E952 |
| Антиоксиданти | E320, E321 |
| Емулгатори | E471, E476 |
| Сгъстители | E407 |
| Фосфати | E450 |

### 🤖 AI Анализ
- Интеграция с Claude (Anthropic API)
- Дълбок анализ с препоръки на български език

## 🔧 Технически детайли

### OCR Поддържани двигатели
1. **EasyOCR** (препоръчително) — поддържа 80+ езика, включително български
2. **pytesseract** — по-бърз, изисква инсталиран Tesseract
3. **Demo mode** — работи без OCR библиотеки (с примерни данни)

### Баркод форматии
- EAN-13, EAN-8 (European Article Number)
- UPC-A, UPC-E (Universal Product Code)
- QR Code
- Code-128, Code-39

### Външни API
- **Open Food Facts** — безплатна база данни с 3M+ продукта
- **Anthropic Claude** — AI анализ
