# 🔍 FoodScan AI v3

## Бързо стартиране

```bash
# 1. Инсталирай зависимостите
pip install -r requirements.txt

# 2. Системни библиотеки (Linux/Mac)
# Linux:  sudo apt-get install libzbar0
# macOS:  brew install zbar

# 3. Стартирай
streamlit run app.py
```

## OCR поддръжка
- **EasyOCR** (препоръчително): `pip install easyocr numpy`
- **Claude Vision** (резервен): работи автоматично при достъп до интернет

## Функции
- 📷 Сканиране: Камера / Снимка / Баркод / Демо
- 🧪 30+ E-числа с подробни описания
- 📊 Здравна оценка 1-10 с разбивка
- ❤️ Рискове: затлъстяване, диабет, сърце, кръвно
- 📄 OCR текст с маркирани E-числа (червено/жълто)
- 🤖 AI дълбок анализ (Claude)
- 📋 История на сканирането
